# THREAD — Every action leaves a trace

Интерактивная игра о медиаграмотности, дезинформации и кибербуллинге.

**UNESCO Youth Hackathon 2026**
Авторы: Nurbibi Kabdyl & Aida Syzdykova

---

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой на Vercel

1. Загрузи эту папку на GitHub как новый репозиторий
2. Зайди на [vercel.com](https://vercel.com) и нажми **Add New Project**
3. Выбери свой репозиторий
4. Vercel автоматически определит настройки (Vite + React)
5. Нажми **Deploy** — готово!

Сайт будет доступен по адресу вида: `thread-game.vercel.app`

---

## О проекте

THREAD — настольная игра, в которой игроки проживают реальные сценарии из цифровой жизни и принимают решения в трёх ролях: распространителя, свидетеля и жертвы. Каждое решение оставляет след.
